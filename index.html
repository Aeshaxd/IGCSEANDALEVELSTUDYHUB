🧩 Original practice

Binary conversion warm-up

Convert denary 13 into 8-bit binary.

O Level CSTry it ↗
Reveal answer

00001101, because 8 + 4 + 1 = 13. Use leading zeroes to make it 8 bits.

✏️ Worked example

Solve a linear equation

Solve 3x + 5 = 20.

O Level MathsSteps below ↓
Show steps

Subtract 5: 3x = 15. Divide by 3: x = 5. Check: 3(5) + 5 = 20.

⚛️ Exam tip

Keep an eye on units

Write the equation first, substitute values with units, then check that your final unit makes sense.

💻 Programming practice

Track a loop

A variable starts at 2. Each loop adds 3, repeating four times. What is the final value?

AS Computer ScienceAnswer below ↓
Reveal answer

14. The values after each pass are 5, 8, 11 and 14.

📈 Worked example

Differentiate a simple function

Find the derivative of y = x² + 3x.

AS MathematicsSteps below ↓
Show steps

Differentiate each term: x² becomes 2x and 3x becomes 3. So dy/dx = 2x + 3.

🇵🇰 Answer tip

Make evidence specific

Support explanatory points with relevant dates, events, examples or named places when the question calls for evidence.

Add your notes & files ♡

PDF notes, revision sheets, images and links can live in your GitHub repository. Upload your file, then add a resource card here so it appears in the library.

Upload files on GitHub ↗
Show me how to add my own file 🌸
  1. Click Upload files on GitHub above and sign in.
  2. Upload your PDF or other file. For example, keep it in a folder such as resources/maths/.
  3. Click Commit changes to save it.
  4. To make it appear in the website library, add a resource card in index.html and link to the file. Uploading alone won't automatically add it to the visible library.
Heads-up: GitHub Pages is a static website, so this button opens GitHub's upload page. It doesn't create a private upload dashboard. Only share resources you have permission to publish, and don't upload private information.
